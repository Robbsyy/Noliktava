# Noliktava

Izstrādājiet noliktavas vadības sistēmu, kurā ir paredzētas trīs lietotāju lomas: administrators, noliktavas darbinieks un plauktu kārtotājs.

Katrai lietotāju lomai jānodrošina atšķirīgas piekļuves tiesības un funkcionalitāte.

1. Administrators

Var izveidot, rediģēt un dzēst lietotāju kontus.

Var piešķirt un mainīt lietotāju lomas un piekļuves tiesības.

Var pievienot, rediģēt un dzēst noliktavas datus.

Var apskatīt un ģenerēt pārskatus par noliktavas darbību.

2. Noliktavas darbinieks

Var pievienot, rediģēt un atjaunināt preču informāciju.

Var izveidot un pārvaldīt pasūtījumus.

Var mainīt pasūtījumu statusus atbilstoši to izpildes procesam.

Var apskatīt un ģenerēt pārskatus par noliktavas darbību.

3. Plauktu kārtotājs

Var apskatīt informāciju par noliktavā esošajām precēm.

Var reģistrēt preču izvietojumu un atrašanās vietu noliktavā.

Var atjaunināt informāciju par preču izvietojumu un veiktajām izmaiņām.

Var sagatavot pārskatus par preču izvietojumu un to stāvokli noliktavā.

Darba prasības

Izveidot sistēmā visas trīs lietotāju lomas.

Nodrošināt katrai lomai atbilstošas piekļuves tiesības.

Izveidot funkcijas, kas ļauj veikt attiecīgajai lomai paredzētās darbības.

Pārbaudīt sistēmas darbību, pieslēdzoties ar katras lomas lietotāja kontu.

Nodrošināt, ka lietotājs nevar veikt darbības, kurām viņam nav piešķirtas tiesības.

Jāizmanto versiju kontroles sistēma, piemēram, Git un GitHub, regulāri veicot jēgpilnus un aprakstošus komitus, kas atspoguļo paveiktās izmaiņas projektā.

Jāievēro datu drošibas principi.

Jāizmanto datu validācija pie ievadlaukiem un citur kur tas ir nepieciešamas.
